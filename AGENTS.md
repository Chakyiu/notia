# Agent guidelines

## Pull requests

- Every PR title MUST start with the Multica issue identifier it implements, in the form `TELE-<number>: <clear summary>` (e.g., `TELE-14: community plugin authoring docs`). The issue number is mandatory — if you don't have one, create or find the issue first.
- Keep the summary after the prefix short and specific (what changed, not how).
- In the PR description, link the Multica issue and post the PR link back on the issue when opened.
